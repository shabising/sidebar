# 🧭 Nexus Sidebar Navigation

A responsive, accessible sidebar navigation built with React, React Router, and Framer Motion.

## ✨ Features

- 📁 **Collapsible Sidebar** — Expand/collapse with button or `[` keyboard shortcut
- 🎯 **Active Link Highlight** — Synced with React Router, supports nested routes
- 📱 **Mobile Friendly** — Hamburger menu with overlay on narrow screens
- 🪗 **Nested Accordion Menus** — Smooth open/close animations with Framer Motion
- 🌙 **Dark Mode** — Toggle between light and dark themes
- ♿ **Accessible** — ARIA labels, keyboard navigation (Tab, Enter, ESC)
- 📦 **Data-Driven** — All menu items managed from a single config file

## 🛠️ Tech Stack

- React 18
- React Router v6
- Framer Motion
- Lucide React (icons)
- CSS (custom, no UI library)
